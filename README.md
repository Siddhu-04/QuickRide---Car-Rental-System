# QuickRide--Car-Rental-System
QuickRide is a simple car rental system that helps users book cars easily. It allows users to find available cars, book rentals, and manage their bookings.

✨ Features
✔ User sign-up & login
✔ Browse and search cars
✔ Book and cancel rentals
✔ Admin panel to manage cars & users

🛠 Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Node.js
Database: MySQL
